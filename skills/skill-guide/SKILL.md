# Skill Guide

## Workflow

1. 사용자가 만들거나 정리하려는 skill repository의 목적을 확인한다.
2. GitHub 관리 구조, Mac 설치, symlink 설치, 검증 절차가 필요하면 `references/skill_guide.md`를 읽는다.
3. 실제 skill 폴더는 `skills/<skill-name>/` 아래에 두고, `SKILL.md`를 필수로 만든다.
4. Codex가 작업 중 참고할 상세 문서는 `references/`에 둔다.
5. 사람이 읽는 문서는 repository 최상위 `docs/`에 둔다.
6. 반복 작업은 repository 또는 skill 내부의 `scripts/`로 자동화한다.
7. 설치 가능한 구조인지 검증한다.

## References

- Codex skill repository 구조와 Mac 설치 방법이 필요하면 `references/skill_guide.md`를 읽는다.
